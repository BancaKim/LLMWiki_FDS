# AI-Hub 이상 판별을 위한 금융거래 정보 및 사용자 패턴 합성데이터

[← 데이터셋 카탈로그](index.md)

> 🇰🇷 **국내(한국) 금융거래 합성데이터** · AI-Hub 데이터셋 번호 **`dataSetSn=71925`**
> (요청 시 적힌 `71295` 는 오기로 보이며, 동일 명칭 데이터셋의 실제 번호는 71925 로 확인)

## 개요
한국 공공 AI 데이터 플랫폼 **[AI-Hub](https://aihub.or.kr)** 에 공개된 **이상거래 탐지(FDS)용 합성 금융거래
데이터**입니다. 실제 금융거래 정보와 **사용자 거래 패턴**을 바탕으로 생성한 **시계열 기반 정상·이상 거래
합성데이터**로, **민감정보(개인·신용정보) 없이** 이상거래 탐지 모델을 학습·검증할 수 있도록 만들어졌습니다.

- **구축 목적**: ① **이상거래 유형 식별**, ② **의심거래 분류의 근거(사유) 추론**.
- **성격**: 국내 금융 도메인(전자금융공동망·카드) 데이터 → 해외 공개 벤치마크(IEEE-CIS·FFSD 등)가
  반영하지 못하는 **한국 결제 환경**을 연구할 때 유용.
- **구축 기관·구축 연도·라이선스 세부**: *(미확인)* — AI-Hub 상세 페이지에서 확인 필요.

## 구조

### 규모 (합성데이터, 공개본)
| 하위 데이터 | 전체 건수 | 이상거래 | 이상 비율 |
|-------------|----------:|---------:|:---------:|
| **전자금융공동망**(계좌이체) 합성데이터 | 4,926,785 | 19,084 | ≈ 0.39% |
| **카드거래** 합성데이터 | 2,169,857 | 80,009 | ≈ 3.69% |
| **합계** | **7,096,642** | **99,093** | ≈ 1.40% |

### 원천 데이터 (합성 전, 비공개)
| 하위 데이터 | 전체 건수 | 이상거래 | 이상 비율 |
|-------------|----------:|---------:|:---------:|
| 전자금융공동망 | 10,071,853 | 10,426 | ≈ 0.10% |
| 카드거래 | 2,230,841 | 60,121 | ≈ 2.70% |
| 합계 | 12,302,694 | 70,547 | — |

> 이상 비율은 위 건수로 계산한 값입니다. 합성 과정에서 **이상거래를 증강**해 원천보다 비율이 높아졌습니다
> (특히 전자금융공동망 0.10% → 0.39%).

### 형식·필드
- 파일 형식: **CSV**(카드거래·전자금융공동망 별도 파일)로 활용된 사례 확인
  ([sugowslt/transaction-anomaly-detection](https://github.com/sugowslt/transaction-anomaly-detection)).
- **컬럼 목록·이상거래 유형(라벨) 체계·사용자/계좌/가맹점 ID 제공 여부**: *(미확인)* — AI-Hub 데이터 명세서
  확인 필요. 명칭상 **거래 정보 + 사용자 패턴** 정보와 **이상 유형·판별 근거** 라벨을 포함하는 것으로 보임 *(미확인)*.

## 특징
- ✅ **합성데이터 → 프라이버시 제약 없음**: 실거래 기반 국내 데이터를 연구·교육용으로 다룰 수 있는 드문 공개본.
- ✅ **두 채널(이체 + 카드)** 을 한 데이터셋에서 비교 가능 — 불균형 정도가 크게 다름(0.39% vs 3.69%).
- ✅ **설명 라벨(판별 근거)** 지향 → [설명가능성(XAI)](../papers/robustness-explainability/index.md)·LLM 기반
  사유 생성 연구와 궁합.
- ⚠️ **네이티브 그래프가 아님(tabular 거래 로그)**. GNN 적용 시 [IEEE-CIS](ieee-cis.md) 처럼 **그래프를 직접 구성**해야 함.
- ⚠️ **AI-Hub 로그인·이용신청 필요**, 반출·재배포 조건은 AI-Hub 약관을 따름 *(세부 미확인)*.
  원본 CSV 재배포는 불가한 것이 일반적(위 GitHub 저장소도 원본 미배포 명시).
- ⚠️ 합성데이터 특성상 **실데이터 대비 분포 차이(sim-to-real gap)** 가능 → 결과 해석 시 주의.

## GNN 적용 가이드 (그래프 구성 아이디어)
식별자 컬럼 제공 여부가 *(미확인)* 이므로, 아래는 **해당 필드가 있을 때**의 일반적 구성 방법입니다.

| 그래프 설계 | 노드 | 엣지 | 참고 모델 |
|-------------|------|------|-----------|
| **거래 그래프(동질)** | 거래 | 같은 사용자/계좌/가맹점/기기 공유 + 시간 인접 | [GTAN](../papers/credit-card-fraud/gtan.md) · [RGTAN](../papers/credit-card-fraud/rgtan.md) (FFSD와 동일 방식) |
| **이종 그래프** | 사용자·계좌·카드·가맹점 | 거래가 엔티티를 연결 | [이종 GNN 계열](../papers/credit-card-fraud/index.md) |
| **계좌 이체 그래프(방향성·동적)** | 계좌 | 송금(시간·금액 속성) | [DIAM](../papers/aml-crypto/diam.md) 류 방향 멀티그래프, 동적 GNN |

- 불균형 대응: 전자금융공동망(≈0.39%)은 극심한 불균형 → **AUPRC·Recall@k** 로 평가
  ([평가지표](../concepts/datasets-overview.md)).
- 참고(비-GNN 베이스라인): 위 GitHub 사례는 scikit-learn 계열 모델로 카드/이체를 **분리 학습** —
  보고치(2024 검증 분할) 카드 PR-AUC ≈ 0.989, 전자금융공동망 PR-AUC ≈ 0.488 *(저장소 자체 보고치, 표준 벤치마크 아님)*.
  → **이체 채널이 훨씬 어렵다**는 점이 관계(그래프) 정보를 활용할 동기가 됨.
